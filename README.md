# MusicStreaming Database Schema

Реляционная схема базы данных для музыкального стримингового сервиса, реализованная на **Microsoft SQL Server (T-SQL)**.

Проект включает в себя полную структуру таблиц, связи (Foreign Keys), индексы для оптимизации запросов и набор тестовых данных для быстрой проверки работоспособности.

## Особенности

- **Нормализация**: схема приведена к 3НФ с учётом связей "многие-ко-многим" через промежуточные таблицы.
- **Гибкая ролевая модель**: поддержка пользователей с разными ролями (`User`, `Artist`, `Admin`, `Moderator`).
- **Связь Артист-Пользователь**: артист может быть привязан к существующему пользователю или существовать отдельно (например, для внешних исполнителей).
- **История прослушиваний**: таблица `Listening` для аналитики и построения рекомендаций.
- **Оптимизация**: настроены индексы по часто используемым полям (жанры, лейблы, даты прослушивания).
- **Каскадное удаление**: для связей альбом-трек и плейлист-трек настроен `ON DELETE CASCADE`.

## Требования

- Microsoft SQL Server 2016 или выше (рекомендуется 2019/2022).
- SQL Server Management Studio (SSMS) или Azure Data Studio.
